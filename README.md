# Longer product description
Kontrol is a free, local-first Markdown workspace designed for people who want their notes to stay as simple plain-text files while still having powerful organization and AI assistance.
Everything is stored as regular Markdown on your computer. You can open the same files in VS Code, Obsidian, Neovim, or any other editor. Kontrol never locks your data into a proprietary format.
On top of the files, Kontrol provides:

- A structured workspace for folders and notes
- Section-level reminders
- Lightweight goals
- Fast search (exact + optional semantic)
- An embedded AI assistant that can open notes, create files, set reminders, summarize content, and more

The AI runs completely locally. No account, no mandatory API keys, and no internet required for core features. The model can be unloaded when not in use so the app stays lightweight.
Kontrol is built for developers and technically inclined users who want a personal knowledge workspace that is private, portable, and actually useful.
